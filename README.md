# The Robot Vacuum's Funniest Excuse

One line, at most 120 characters, in which a robot vacuum explains why it
missed a spot — its official apology for the crumb that got away.

> I didn't miss the spot: the crumb pays rent in pet hair, so by house rules it's a tenant, not dirt.

`main.py` (standard library only) writes that line to the output file
resolved from `ENTRY_OUTPUT`, `OUTPUT_DIR` / `MAKEFUN_OUTPUT_DIR`, or
`/output/entry.txt`.
